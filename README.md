## 🎯 ¿Qué es Finti?

**Finti** es una aplicación de gestión diseñada para emprendedores y pequeños negocios que necesitan ordenar su actividad económica de forma simple, rápida y accesible.

Centraliza en una sola plataforma:

- ventas  
- cobranzas  
- stock  
- costos  
- finanzas  
- contabilidad básica  

---

## 🚨 Problema

Muchos emprendedores:

- no registran sus ventas correctamente  
- pierden control de las cuotas y cobranzas  
- no saben cuánto ganan realmente  
- gestionan todo de forma manual o desordenada  

Esto limita su crecimiento y toma de decisiones.

---

## 💡 Solución

Finti permite:

- 📊 visualizar el estado del negocio en tiempo real  
- 💰 registrar ventas de forma rápida  
- 📅 gestionar cobranzas y cuotas  
- 📦 controlar stock y costos  
- 🧾 generar comprobantes en PDF  
- 📉 acceder a información financiera clara  

---

## 🧩 Módulos principales

### 📊 Dashboard
- dinero en caja  
- ingresos del día  
- ventas recientes  
- cobranzas pendientes  

---

### 💰 Ventas
- registro automático  
- almacenamiento en base de datos  
- emisión de comprobantes  

---

### 📅 Cobranzas
- control de cuotas  
- alertas de vencimiento  
- seguimiento de pagos  

---

### 📦 Stock y Costos
- control de inventario  
- cálculo de costos  

---

### 🧾 Contabilidad
- registro de movimientos  
- estados contables básicos  

---

### 👤 Finanzas personales
- control separado del negocio  

---

## 🛠️ Tecnologías

- ⚛️ React + TypeScript  
- ⚡ Vite  
- 🎨 Tailwind CSS  
- 🧠 Supabase (backend y base de datos)  
---

## ⚙️ Instalación

```bash
git clone https://github.com/Finti-proyect/finti-frontend.git
cd finti-frontend
npm install
npm run dev
````
